🏦 Banking System Using Python
This project is a simple Banking System developed using Python to simulate basic banking operations. It demonstrates fundamental Python programming concepts such as classes, objects, functions, conditional statements, loops, user input, and data validation.
📌 Project Features
- 🔐 Account Login
  - Users can log in using a username and password.
  - Validates the entered login credentials.
  - Displays an appropriate error message for invalid login attempts.
  - Limits the number of login attempts.
- 💰 Deposit Money
  - Allows logged-in users to deposit money.
  - Deposit amount must be greater than zero.
  - Updates and displays the current account balance after the deposit.
- 💸 Withdraw Money
  - Allows users to withdraw money from their account.
  - Withdrawal amount must be greater than zero.
  - Prevents withdrawal when the amount is greater than the available balance.
  - Displays the remaining balance after withdrawal.
- 📊 Check Balance
  - Users can view their current account balance at any time after logging in.
🛠️ Technologies Used
- Python
- Object-Oriented Programming (OOP)
- Conditional Statements
- Loops
- Functions
- User Input & Validation
🎯 Objective
The main objective of this project is to create a basic banking application while improving understanding of Python programming, logical thinking, user authentication, balance management, and error handling.
📚 Learning Outcome
Through this project, I learned how to use Python to create a simple real-world application. I understood how classes and methods can be used to organize a program, how to validate user inputs, manage account balances, and implement login and banking operations securely.
